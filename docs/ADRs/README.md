# Architecture Decision Records

Each subdirectory is one feature, named by its feature slug. Inside, ADRs are numbered in the order they were decided
(`0001-...`, `0002-...`). Each feature's own `README.md` lists its decisions.

ADRs record decisions. Exploratory notes and ideas that haven't been decided go in [`../design-notes/`](../design-notes/).

Terms introduced by ADRs go in the [ADR glossary](./glossary.md), unless they are repo-wide concepts. Those go in the
main [glossary](../glossary.md).

ADRs are written with the `feature-adr` Claude Code skill, which interviews you one decision at a time. They can also be
written by hand, following the same layout.
